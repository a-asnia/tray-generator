# Карта проекта для Claude

Параметрический генератор 3D-печатных лотков. Всё приложение — один файл
`tray-generator.html`, который собирается офлайн из модулей `src/`
конкатенацией (`node build.mjs`). Интерфейс и коммиты — по-русски.

## Экономия контекста — читай это, а не весь проект

- **НИКОГДА не читай `tray-generator.html`** — он генерируется из `src/`
  (~5300 строк). Правки только в `src/`, потом пересборка.
- Не читай большие файлы целиком. Порядок работы: эта карта → `Grep` по
  якорям `── … ──` (секции размечены во всех крупных файлах) → `Read`
  с offset/limit только нужного региона.
- Правила заказчицы собраны в `ТЗ.md` — при вопросе «как должно себя вести»
  сначала смотри туда, а не в код. Новые правила дописывай в `ТЗ.md`.
- `README.md` — для пользователя (не для тебя).

## Команды

```
node build.mjs                       # сборка tray-generator.html (+проверки)
node build.mjs --artifact <путь>     # фрагмент для artifact-превью
node tests/<набор>.mjs               # один node-набор (секунды) — основной способ
node tests/run.mjs --quiet           # все node-наборы (~1–2 мин)
NODE_PATH=$(npm root -g) node tests/browser/<x>-test.cjs   # один браузерный тест
node tests/run-browser.mjs           # ВСЕ браузерные (>10 мин — только в фоне!)
node tests/fingerprint.mjs --update  # после НАМЕРЕННОГО изменения геометрии
```

Точечная правка → гоняй только релевантные наборы + `fingerprint.mjs`;
полный браузерный прогон — фоном перед пушем крупных правок.
`sleep` в Bash заблокирован — ждать только until-циклом или фоновой задачей.

## Сборка: главные грабли

- `build.mjs` просто склеивает модули в один `<script>`: **top-level имена
  всех модулей обязаны быть уникальны** (коллизия = SyntaxError во всех
  браузерных тестах). Поэтому `r1` существует как `lmR1`/`lgR1`/`round1`.
- Новый модуль добавляется в список `MODULES` в `build.mjs` — порядок важен
  (зависимости раньше зависимых).
- `tray-generator.html` коммитится вместе с исходниками в каждом коммите.

## Карта модулей (что где править)

| Файл | За что отвечает |
|---|---|
| `src/App.jsx` (1.6k строк) | вся панель UI: состояние, история undo/redo, план раскладки с drag, вкладки. Секции: `── шаг назад ──`, `── план раскладки ──`, `── перетаскивание по плану ──`, `── редакторы: стенка/линия и ячейка ──`, `── вкладка «Раскладка/Принтер/Контейнеры»` |
| `src/model/build.js` (1.3k) | геометрия ОДНОГО контейнера (стенки, полы, горка, замки, окна визитницы). Секции: `── Зона замка ──`, `── Окна под съёмную визитницу ──`, `── Радиусы углов ──`, `── Фиксированные ячейки ──`, `── Вставные стенки ──` |
| `src/model/laymove.js` | свободная 2D-раскладка: `moveContainer`, `snapMove` (прилипание 8 мм), `resizeBox`, `fitAssembly` (жёсткая рамка+парковка), `freeRects`/`autoSpot`, `pinnedPos` (прижатие `c.pin` к сторонам) |
| `src/model/laymagnet.js` | «магнит раскладки»: `snapLayout` (щели <30 мм — растяжкой, больше — новыми контейнерами), `fillAll` |
| `src/model/assembly.js` | стыковка соседей по фактическому касанию граней → `conn` для build.js; `railCarrier` (горка всегда несёт рельс) |
| `src/model/layout.js` | сетка ячеек внутри контейнера, ширины/глубины рядов, лимиты деления (ячейка ≥5 мм) |
| `src/model/connectors.js` | константы «ласточкиного хвоста» (`CONN`, зазор 0.35) |
| `src/model/inserts.js` | вставные перегородки (egg-crate, низ по уровням полов) |
| `src/model/cardholder.js` | съёмная визитница (`CARDH`, wallH=64) |
| `src/model/presets.js` | пресеты (низкий, деления, органайзер, горка, буклетница) |
| `src/state/storage.js` | (де)сериализация проекта, `makeContainer`, миграции старых форматов |
| `src/scene/useTrayScene.js` | three.js: сцена, камера, пикинг |
| `src/ui/*` | мелкие компоненты (Param, Collapse, Schematic), тема |
| `src/geometry/*` | примитивы: призмы, STL-экспорт, вектора |

## Ключевые инварианты (нарушишь — сломаешь тесты)

- **Раскладка свободная**: позиция контейнера — `px`/`pz` в мм, никаких
  рядов/клеток; пересечения запрещены всегда; рамка стола жёсткая,
  непоместившееся паркуется целиком СНАРУЖИ рамки (px за правым краем).
- **`conn[сторона]` — СПИСОК групп `{male, vs}`** (соседей у стенки может
  быть несколько), не одиночный объект. Каждая male-группа обязана
  восстановить стенку через `zoneWall` — иначе сквозные дыры в ячейках.
- **История**: правки склеиваются окном 400 мс; после undo/redo действует
  окно «доводки» (`settling`) — нормализующие эффекты не считаются шагом.
- Геометрия только аддитивная (выпуклые призмы), «отверстия» — промежутки
  между телами. За габарит контейнера торчит только рельс замка.
- Ограничение элемента применяется к элементу сразу (галка визитницы сама
  поднимает стенку до 64 мм и т.п.) — см. `ТЗ.md` п. 1.1.

## Процесс завершения любой правки

1. Релевантные тесты зелёные (+`fingerprint`, при намеренной смене
   геометрии — `--update`).
2. `node build.mjs`; коммит исходников вместе с `tray-generator.html`,
   сообщение по-русски.
3. `git push -u origin claude/tray-generator-modular-vite-531gqd` — сайт
   <https://a-asnia.github.io/tray-generator/> обновится сам (workflow
   `pages.yml` кладёт файл в ветку `gh-pages`; её руками не трогать).
4. Обновить artifact-превью: `node build.mjs --artifact <scratchpad>/tray-app-v4.html`
   и переопубликовать тот же артефакт (тот же путь файла → тот же URL).
5. Отправить свежий `tray-generator.html` пользовательнице (SendUserFile).
