# Генератор лотков — система контейнеров для 3D-печати

Параметрический генератор контейнеров-органайзеров: ячейки, стенки с узорами
(соты, линии), соединители «ласточкин хвост», экспорт в STL. Всё приложение —
один файл **`tray-generator.html`** в корне этого репозитория. Его не нужно
устанавливать или собирать: это готовая страница, которая целиком работает
сама по себе.

## Как залить приложение на свой сервер

Ровно три шага, ничего устанавливать не нужно:

1. Открой файл **`tray-generator.html`** здесь, на GitHub (кликни по нему в
   списке файлов в корне репозитория).
2. Нажми кнопку **«Download raw file»** (значок со стрелкой вниз, справа
   сверху над содержимым файла). Файл скачается на компьютер.
3. Залей скачанный файл на свой сервер — так же, как ты делал это раньше.
   Это единственный нужный файл: все скрипты и стили уже внутри него.

Готово. Открой страницу на своём сервере — генератор работает.

## Как внести изменения в приложение

Попроси Claude (в новой сессии Claude Code на этом репозитории) сделать
нужное изменение. Claude поменяет исходники, сам пересоберёт
`tray-generator.html`, проверит его и закоммитит в корень репозитория.
После этого повтори три шага выше, чтобы обновить файл на сервере.

## Техническая часть

*Эта секция — для Claude и разработчиков. Владельцу репозитория ничего
из неё запускать не нужно.*

### Структура исходников

```
src/
  main.jsx               — монтирование React-приложения
  App.jsx                — панель UI с вкладками, редакторы, экспорт
  geometry/
    vec.js               — векторные операции
    solids.js            — выпуклые призмы, профиль стенки, пандус
    random.js            — детерминированный ГПСЧ, лента-«прядь»
    stl.js               — экспорт STL (мм, вертикаль — Z), объём, сварка вершин
    manifold.js          — ленивая загрузка Manifold (цельный STL)
  model/
    layout.js            — раскладка ячеек, ключи стенок, свойства стенок/ячеек
    connectors.js        — «ласточкин хвост»: константы, зоны, тела
    build.js             — сборка контейнера: стенки, узоры, пол-лесенка
  state/
    storage.js           — контейнеры по умолчанию, автосохранение в localStorage
  scene/
    useTrayScene.js      — three.js: сцена, орбитальная камера, пикинг кликом
  ui/
    theme.js             — цвета и шрифты
    controls.jsx         — Param, Stepper, Collapse, SectionTitle
    Schematic.jsx        — плоская схема контейнера с выбором стенок/ячеек
legacy/                  — исходный монолит v31 и старая CDN-сборка (справочно)
```

### Сборка (выполняет Claude в облачной среде)

```
npm install        # один раз
npm run dev        # предпросмотр на http://localhost:5173
npm run build      # сборка: dist/index.html → копируется в tray-generator.html
```

Сборка настроена через Vite + `vite-plugin-singlefile`: на выходе один
самодостаточный HTML (React, three.js и весь код приложения инлайном, без
CDN). Единственное исключение — библиотека Manifold для кнопки «Скачать
цельный STL»: она, как и в оригинале, лениво подгружается с CDN при нажатии
кнопки, а при недоступности сети экспорт автоматически откатывается на
обычный STL.

После любых изменений геометрии прогоняется тест эквивалентности ядра
(сравнение solids с эталоном) и собирается `tray-generator.html`; файл
коммитится в корень вместе с исходниками.

### Инварианты (нарушать нельзя)

- Элементы одной ячейки никогда не пересекают внутренний объём соседней.
- Наружные плоскости внешних стенок идеально ровные: на них стыковка
  контейнеров и пазы соединителей (паз прячется внутри толщины стенки).
- Все размеры в миллиметрах; в STL вертикаль — ось Z.
- Узоры печатаются без поддержек: соты вершиной вверх, линии диагональные.
